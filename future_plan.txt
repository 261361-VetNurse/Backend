===========================================
1. สถานะปัจจุบัน (Current State)
===========================================

Endpoint: GET /pet-owners/home-page

ปัญหา:
- N+1 Query Problem ใน Medicine Notifications
  * 1 query หา notifications + N queries หา medicines + N queries หา pets
  * ตัวอย่าง: 5 notifications = 1 + 5 + 5 = 11 queries

- N+1 Query Problem ใน Appointments  
  * 1 query หา appointments + N queries หา pets + N queries หา notifications
  * ตัวอย่าง: 3 appointments = 1 + 3 + 3 = 7 queries

รวมทั้งหมด: ~18-22 queries ต่อ 1 request
Response Time: 300-500ms (ประมาณการ)

2. แผนการปรับปรุง (Optimization Plan)
===========================================

PRIORITY 1 - เพิ่ม Database Indexes (ง่าย, ได้ผลทันที)
-----------------------------------------------------
สร้างไฟล์: app/schemas/create_indexes.py

Indexes ที่ต้องสร้าง:
1. JWT.access_token (unique index)
   - ใช้ทุก request สำหรับ authentication
   
2. MEDICINES_NOTIFICATION(user_id, notification_at)
   - ใช้ query หาการแจ้งเตือนยาของ user ในช่วงเวลา
   
3. APPOINTMENTS(user_id, appointment_date)  
   - ใช้ query หานัดหมายของ user ที่กำลังจะมาถึง
   
4. Foreign Key Indexes:
   - MEDICINES_NOTIFICATION.medicine_id
   - MEDICINES_NOTIFICATION.pet_id
   - APPOINTMENTS_NOTIFICATION.appointment_id

ผลลัพธ์คาดหวัง:
✅ Query เร็วขึ้น 3-5 เท่า
✅ ลด database load
✅ ไม่ต้องแก้ไข code

วิธีรัน:
```bash
python app/schemas/create_indexes.py
```


PRIORITY 2 - Aggregation Pipeline (ซับซ้อน, ได้ผลมาก)
-----------------------------------------------------
ไฟล์ที่ต้องแก้: app/routers/pet_owners_home_page.py

2.1 Medicine Notifications (บรรทัด 67-103)
------------------------------------------
เปลี่ยนจาก:
- find() + loop + find_one() ทีละตัว

เป็น:
- aggregate() + $lookup ครั้งเดียวได้หมด

Pipeline ที่ต้องใช้:
```python
pipeline = [
    {"$match": {"user_id": user_id, "notification_at": {...}}},
    {"$lookup": {"from": "MEDICINES", "localField": "medicine_id", ...}},
    {"$lookup": {"from": "PETS", "localField": "pet_id", ...}},
    {"$unwind": "$medicine"},
    {"$unwind": "$pet"}
]
```

ผลลัพธ์: ลดจาก 1+2N queries → 1 query


2.2 Appointments (บรรทัด 105-136)
---------------------------------
เปลี่ยนจาก:
- find() + sort() + loop + find_one() ทีละตัว

เป็น:
- aggregate() + $lookup ครั้งเดียวได้หมด

Pipeline ที่ต้องใช้:
```python
pipeline = [
    {"$match": {"user_id": user_id, "appointment_date": {...}}},
    {"$sort": {"appointment_date": 1}},
    {"$lookup": {"from": "PETS", ...}},
    {"$lookup": {"from": "APPOINTMENTS_NOTIFICATION", ...}},
    {"$unwind": "$pet"},
    {"$unwind": "$notification"}
]
```

ผลลัพธ์: ลดจาก 1+2N queries → 1 query
